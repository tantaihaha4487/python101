# พื้นฐาน Python

บทนี้คือรากฐานของทุกโปรแกรม: ตัวแปร ชนิดข้อมูล comment และการแสดงผล

## ตัวแปร

ตัวแปรคือชื่อที่ใช้เก็บค่า

```python
name = "Mali"
age = 16
height = 165.5
is_student = True
```

Python ไม่ต้องประกาศชนิดข้อมูลล่วงหน้า โปรแกรมจะดูจากค่าที่ใส่ให้ตัวแปร

เราสร้างตัวแปรพร้อมกำหนดค่าเริ่มต้นได้ทันที:

```python
item_count = 0
section = "B"
gravity = 9.81
faculty = "SCI"
is_member = False
temperature_offset = -3
```

Python ไม่มีชนิด `char` แยกต่างหาก อักขระหนึ่งตัวเป็นเพียง `str` ที่มีความยาว 1

## การตั้งชื่อตัวแปร

ชื่อตัวแปรต้องขึ้นต้นด้วยตัวอักษรหรือ `_` และมีได้เฉพาะตัวอักษร ตัวเลข และ `_` เท่านั้น ห้ามมีช่องว่างหรือเครื่องหมาย `+ - , .` ห้ามใช้คำสงวนของ Python และตัวพิมพ์เล็ก-ใหญ่ถือเป็นคนละชื่อ เช่น `age` กับ `Age`

| ชื่อตัวแปร | ใช้ได้ไหม | เหตุผล |
| --- | --- | --- |
| `songkran_day` | ✓ | ใช้ตัวอักษรและ `_` |
| `2nd_place` | ✗ | ขึ้นต้นด้วยตัวเลข |
| `_2nd_place` | ✓ | ขึ้นต้นด้วย `_` ได้ |
| `class` | ✗ | เป็นคำสงวน |
| `x-y` | ✗ | มีเครื่องหมาย `-` |
| `first name` | ✗ | มีช่องว่าง |

ดูรายการคำสงวนทั้งหมดได้ด้วย:

```python
import keyword
print(keyword.kwlist)
```

ใช้ `snake_case`:

```python
student_name = "Anan"
total_score = 95
```

หลีกเลี่ยงชื่อสั้นเกินไป เช่น `x` ถ้าไม่ใช่โค้ดทดลอง เพราะอ่านยาก

## ชนิดข้อมูลพื้นฐาน

| ชนิด | ตัวอย่าง | ใช้ทำอะไร |
| --- | --- | --- |
| `str` | `"hello"` | ข้อความ |
| `int` | `10` | จำนวนเต็ม |
| `float` | `3.14` | ทศนิยม |
| `bool` | `True` | จริง/เท็จ |
| `list` | `["a", "b"]` | ลำดับข้อมูลที่แก้ไขได้ |
| `tuple` | `("a", "b")` | ลำดับข้อมูลที่แก้ไขไม่ได้ |
| `dict` | `{"name": "Mali"}` | ข้อมูลแบบคู่ key-value |
| `set` | `{"a", "b"}` | กลุ่มข้อมูลไม่ซ้ำ |

ข้อมูลแบบกลุ่มเหล่านี้จะอธิบายอย่างละเอียดในบท [โครงสร้างข้อมูล](./data-structures.md)

| --- | --- |

| `"Chiang Mai"` | `str` |
| `["a", "b"]` | `list` |
| `True` | `bool` |
| `9.81` | `float` |
| `{"a", "b"}` | `set` |

## ตรวจและแปลงชนิดข้อมูล

ตรวจชนิดข้อมูลด้วย `type()`:

```python
print(type("hello"))
print(type(10))
```

ใช้ `int()`, `float()`, `str()` และ `bool()` เพื่อสร้างหรือแปลงค่าเป็นชนิดที่ต้องการ:

```python
print(float(5))
print(int(5.5))
print(int(-5.9))
print(int("5") + 1)
print(float("5.5") + 1)
print(True)
```

ผลลัพธ์:

```text
5.0
5
-5
6
6.5
True
```

จำให้แม่นว่า `int()` **ตัดทศนิยมทิ้ง ไม่ใช่ปัดเศษ** โดยตัดเข้าหาศูนย์ ดังนั้น `int(-5.9)` จึงเป็น `-5` ไม่ใช่ `-6` ส่วนการแปลงข้อความที่ผู้ใช้ป้อนจะเรียนต่อในบท [Input และ Output](./input-output.md)

## การแสดงผล

ใช้ `print()` เพื่อแสดงข้อมูล

```python
name = "Mali"
print("Hello", name)
print("Hello " + name)
print(f"Hello {name}")
```

ใช้ `+` ต่อข้อความกับตัวแปรข้อความได้ เช่น `"Hello " + name`
`f-string` ช่วยแทรกค่าตัวแปรในข้อความ อ่านง่ายและใช้บ่อยมาก

กำหนดให้เลขทศนิยมแสดงสองตำแหน่งได้ด้วย `:.2f`:

```python
value = 3.14159
print(f"{value:.2f}")
```

ผลลัพธ์:

```text
3.14
```

บท [Input และ Output](./input-output.md) จะสอนการรับค่าจริงจากผู้ใช้และการแสดงผลเพิ่มเติม

## Comment

Comment คือข้อความที่ Python ไม่รัน ใช้อธิบายโค้ดที่อาจอ่านยาก

```python
# คำนวณราคาหลังลด 10%
price = 100
final_price = price * 0.9
```

## ตัวดำเนินการทางคณิตศาสตร์

| ตัวดำเนินการ | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
| --- | --- | --- | --- |
| `+` | บวก | `7 + 2` | `9` |
| `-` | ลบ | `7 - 2` | `5` |
| `*` | คูณ | `7 * 2` | `14` |
| `/` | หาร | `7 / 2` | `3.5` |
| `//` | หารปัดเศษลง | `7 // 2` | `3` |
| `%` | เศษจากการหาร | `7 % 2` | `1` |
| `**` | ยกกำลัง | `7 ** 2` | `49` |

```python
print(2 ** 10)
print(27 % 12)
print(10 / 2)
print(10 // 3)
n = 9
print((n * (n + 1)) / 2)
```

ผลลัพธ์:

```text
1024
3
5.0
3
45.0
```

ตัวดำเนินการ `/` **ให้ค่าเป็น float เสมอ** แม้หารลงตัว ดังนั้น `10 / 2` จึงเป็น `5.0` ไม่ใช่ `5`

## ตัวดำเนินการกำหนดค่า

`=` ใช้กำหนดค่า ส่วน `+=`, `-=`, `*=` และ `/=` คำนวณจากค่าเดิมแล้วเก็บผลกลับในตัวแปรเดิม

```python
count = 8
count += 12
print(count)
count -= 5
print(count)
```

ผลลัพธ์:

```text
20
15
```

เมื่อใช้ `+=` กับ `str` Python จะต่อข้อความแทนการบวกตัวเลข

## ลำดับการคำนวณ

Python คำนวณตามลำดับนี้ และตัวดำเนินการระดับเดียวกันจะทำจากซ้ายไปขวา:

1. วงเล็บ `()`
2. ยกกำลัง `**`
3. คูณและหาร `* / // %`
4. บวกและลบ `+ -`

```python
print(2 + 3 * 4 ** 2)
print((2 + 3) * 4)
```

ผลลัพธ์:

```text
50
20
```

นิพจน์แรกคำนวณ `4 ** 2` เป็น 16 แล้วคูณ 3 เป็น 48 ก่อนบวก 2

## ฟังก์ชันคณิตศาสตร์ที่ใช้บ่อย

| ฟังก์ชัน | ตัวอย่าง | ผลลัพธ์ |
| --- | --- | --- |
| ค่าสัมบูรณ์ | `abs(-1980)` | `1980` |
| ปัดเป็นจำนวนเต็ม | `round(58.72)` | `59` |
| ปัดตามตำแหน่ง | `round(3.14159, 2)` | `3.14` |
| ตัดทศนิยม | `int(58.72)` | `58` |
| ยกกำลัง | `4 ** 3` | `64` |
| รากที่สอง | `math.sqrt(225)` | `15.0` |
| รากที่สองด้วยเลขยกกำลัง | `225 ** 0.5` | `15.0` |
| ปัดลง | `math.floor(58.72)` | `58` |
| ปัดขึ้น | `math.ceil(58.12)` | `59` |

ทั้ง `math.sqrt()` และ `** 0.5` ให้ค่าเป็น **float** คือ `15.0` ไม่ใช่ `15` ส่วน `math.floor`, `math.ceil` และ `math.sqrt` ต้องเขียน `import math` ก่อนใช้ อ่านเรื่องการ import ต่อในบท [โมดูล](./modules.md)

## ข้อผิดพลาดที่พบบ่อย

```python
age = "16"
print(age + 1)  # error เพราะข้อความบวกเลขไม่ได้
```

แก้โดยแปลงชนิดข้อมูล:

```python
age = int("16")
print(age + 1)
```

- คิดว่า `int(5.9)` จะปัดขึ้นเป็น 6 ทั้งที่จริงได้ 5
- คิดว่า `/` จะให้จำนวนเต็ม ทั้งที่จริงให้ `float`
- ใช้คำสงวนเป็นชื่อตัวแปร
- ลืมวงเล็บแล้วลำดับการคำนวณเปลี่ยนผลลัพธ์
- `5 / 0` ทำให้เกิด `ZeroDivisionError`
