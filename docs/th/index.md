# คอร์ส Python ภาษาไทยสำหรับผู้เริ่มต้น

ยินดีต้อนรับสู่คอร์ส Python ภาษาไทยสำหรับผู้เริ่มต้นของ Python101 คอร์สนี้ออกแบบมาสำหรับคนที่เริ่มจากศูนย์ ไม่จำเป็นต้องเคยเขียนโปรแกรมมาก่อน เป้าหมายคือให้คุณอ่านโค้ด Python ออก เขียนโปรแกรมเล็ก ๆ ได้ และมีพื้นฐานพร้อมต่อยอดไปทำเว็บ วิเคราะห์ข้อมูล หรือระบบอัตโนมัติ

## วิธีเรียน

1. อ่านคำอธิบายให้เข้าใจก่อนคัดลอกโค้ด
2. พิมพ์โค้ดเองอย่างน้อยหนึ่งรอบ
3. ลองเปลี่ยนค่าตัวแปรและดูผลลัพธ์
4. ทำแบบฝึกหัดท้ายบท
5. ถ้าเจอ error ให้อ่านข้อความ error ก่อนค้นหาคำตอบ

## เริ่มจากตรงไหน

- [Flowchart](./flowchart.md) ฝึกคิดเป็นขั้นตอนก่อนเขียนโค้ด
- [Pseudocode](./pseudocode.md) เขียนขั้นตอนเป็นข้อความก่อนแปลงเป็นโค้ด
- [Setup](./setup.md) ติดตั้ง Python และรันไฟล์แรก
- [Basics](./basics.md) เรียนตัวแปร ชนิดข้อมูล และ output
- [Roadmap](./roadmap.md) ดูภาพรวมการเรียน 4 สัปดาห์
- [Projects](./projects.md) ฝึกทำโปรเจกต์จริง

## สิ่งที่จะได้เรียน

- ออกแบบขั้นตอนด้วยผังงานและรหัสเทียม
- ติดตั้ง Python และรันไฟล์ `.py`
- ตัวแปร ชนิดข้อมูล ตัวดำเนินการ และการแสดงผล
- รับข้อมูลจากผู้ใช้และแปลงชนิดข้อมูล
- เงื่อนไข ลูป และโครงสร้างข้อมูล
- ฟังก์ชัน ไฟล์ error handling และ modules
- พื้นฐาน OOP และโปรเจกต์สำหรับผู้เริ่มต้น

## เส้นทางแนะนำ

เริ่มจาก [ผังงาน](./flowchart.md) และ [รหัสเทียม](./pseudocode.md) เพื่อฝึกคิดเป็นขั้นตอนก่อน แล้วค่อย [ติดตั้งเครื่องมือ](./setup.md) จากนั้นเรียนตามลำดับใน sidebar ทางซ้าย หากมีพื้นฐานแล้วสามารถข้ามไปบทที่ต้องการได้ แต่สำหรับมือใหม่ควรเรียนเรียงลำดับเพราะแต่ละบทต่อยอดจากบทก่อนหน้า
