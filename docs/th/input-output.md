# Input และ Output

โปรแกรมที่ดีมักไม่ได้แค่แสดงผล แต่รับข้อมูลจากผู้ใช้และตอบสนองตามข้อมูลนั้น

## รับข้อมูลด้วย input

```python
name = input("ชื่อของคุณ: ")
print(f"สวัสดี {name}")
```

ค่าที่ได้จาก `input()` จะเป็นข้อความเสมอ แม้ผู้ใช้จะพิมพ์ตัวเลข

## แปลงชนิดข้อมูล

```python
age_text = input("อายุ: ")
age = int(age_text)
print(f"ปีหน้าคุณจะอายุ {age + 1}")
```

ฟังก์ชันที่ใช้บ่อย:

- `int()` แปลงเป็นจำนวนเต็ม
- `float()` แปลงเป็นทศนิยม
- `str()` แปลงเป็นข้อความ

## ตัวอย่าง: เครื่องคิดเลขง่าย ๆ

```python
first = float(input("เลขตัวแรก: "))
second = float(input("เลขตัวที่สอง: "))

print(f"ผลบวก = {first + second}")
print(f"ผลลบ = {first - second}")
print(f"ผลคูณ = {first * second}")
print(f"ผลหาร = {first / second}")
```

ตัวอย่างการรัน:

```text
เลขตัวแรก: 10
เลขตัวที่สอง: 2
ผลบวก = 12.0
ผลลบ = 8.0
ผลคูณ = 20.0
ผลหาร = 5.0
```

## การจัดรูปแบบตัวเลข

```python
price = 199.987
print(f"ราคา {price:.2f} บาท")
```

`:.2f` หมายถึงแสดงทศนิยม 2 ตำแหน่ง

ผลลัพธ์คือ:

```text
ราคา 199.99 บาท
```

## ข้อผิดพลาดที่พบบ่อย

- ลืมแปลง `input()` เป็นตัวเลขก่อนคำนวณ
- ผู้ใช้กรอกตัวอักษรในช่องที่ต้องเป็นตัวเลข
- หารด้วยศูนย์ ทำให้เกิด `ZeroDivisionError`

## แบบฝึกหัด

1. รับราคาสินค้า 2 ชิ้นจากผู้ใช้ แปลงเป็น `float` แล้วแสดงราคารวมเป็นทศนิยม 2 ตำแหน่งเสมอ
2. รับเกรดเฉลี่ยของเทอมต้นและเทอมปลาย แปลงเป็น `float` คำนวณเกรดเฉลี่ยรวมของปีนั้น แล้วแสดงผลทศนิยม 2 ตำแหน่ง
3. รับราคาสินค้าและเปอร์เซ็นต์ส่วนลด แปลงเป็น `float` แล้วแสดงราคาหลังหักส่วนลด

### เฉลยข้อ 1

`input()` ได้ข้อความเสมอ จึงต้องใช้ `float()` ก่อนนำราคามาบวกกัน และใช้ `:.2f` เพื่อให้แสดงทศนิยม 2 ตำแหน่งเสมอ

```python
price1 = float(input("ราคาสินค้าชิ้นที่ 1: "))
price2 = float(input("ราคาสินค้าชิ้นที่ 2: "))
total = price1 + price2
print(f"ราคารวมคือ {total:.2f} บาท")
```

### เฉลยข้อ 2

แปลงเกรดเป็น `float` เพราะเป็นเลขทศนิยม แล้วหารด้วยจำนวนเทอม

```python
gpa1 = float(input("GPA เทอมต้น: "))
gpa2 = float(input("GPA เทอมปลาย: "))
average = (gpa1 + gpa2) / 2
print(f"เกรดเฉลี่ยรวมคือ {average:.2f}")
```

### เฉลยข้อ 3

คำนวณส่วนลดจากเปอร์เซ็นต์ก่อน แล้วนำไปลบออกจากราคาตั้งต้น

```python
price = float(input("ราคาสินค้า: "))
discount = float(input("ส่วนลด (%): "))
final_price = price - (price * discount / 100)
print(f"ราคาสุทธิ: {final_price:.2f} บาท")
```

## Mini challenge

สร้างโปรแกรมที่รับอุณหภูมิ Celsius จากผู้ใช้ แปลงเป็น `float` คำนวณ Fahrenheit ด้วยสูตร `F = C * 9 / 5 + 32` แล้วแสดงทั้งค่า Celsius และ Fahrenheit

<details class="answer-reveal">
<summary>ดูเฉลย Mini challenge</summary>

สูตรนี้ต้องแปลงค่า input เป็น `float` เพื่อให้คำนวณกับทศนิยมได้

```python
celsius = float(input("อุณหภูมิ Celsius: "))
fahrenheit = celsius * 9 / 5 + 32

print(f"{celsius:.1f} C = {fahrenheit:.1f} F")
```

ตัวอย่างการรัน:

```text
อุณหภูมิ Celsius: 25
25.0 C = 77.0 F
```

</details>
