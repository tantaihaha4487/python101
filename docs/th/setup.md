# ติดตั้งและเริ่มรัน Python

บทนี้ทำให้เครื่องของคุณพร้อมเขียน Python และเข้าใจวิธีรันไฟล์อย่างถูกต้อง

## Python คืออะไร

Python เป็นภาษาโปรแกรมที่อ่านง่าย ใช้ได้หลายงาน เช่น เว็บ ระบบอัตโนมัติ วิเคราะห์ข้อมูล AI และสคริปต์เล็ก ๆ ข้อดีของ Python สำหรับผู้เริ่มต้นคือ syntax ไม่ซับซ้อนและมีชุมชนขนาดใหญ่

## ติดตั้ง Python

1. ไปที่ `https://www.python.org/downloads/`
2. ดาวน์โหลด Python เวอร์ชัน 3.12 หรือใหม่กว่า
3. บน Windows ให้เลือก `Add Python to PATH` ระหว่างติดตั้ง
4. เปิด terminal แล้วตรวจสอบ:

```bash
python --version
```

บางเครื่องอาจต้องใช้:

```bash
python3 --version
```

## ติดตั้ง editor

แนะนำ VS Code เพราะใช้ง่ายและมีส่วนเสริม Python

1. ติดตั้ง VS Code
2. เปิด Extensions
3. ติดตั้ง extension ชื่อ `Python` จาก Microsoft

## สร้างไฟล์แรก

สร้างไฟล์ชื่อ `hello.py`

```python
print("Hello, Python101")
print("สวัสดี Python")
```

รันไฟล์:

```bash
python hello.py
```

## REPL คืออะไร

REPL คือโหมดทดลองคำสั่งทีละบรรทัด เปิดด้วย:

```bash
python
```

ลองพิมพ์:

```python
1 + 2
print("test")
```

ออกจาก REPL ด้วย `exit()`

## ข้อผิดพลาดที่พบบ่อย

- ติดตั้งแล้วแต่ใช้ `python` ไม่ได้: ตรวจสอบ PATH หรือใช้ `python3`
- รันผิด folder: ใช้ `pwd` หรือ `dir` เพื่อตรวจว่าคุณอยู่ที่ไหน
- ชื่อไฟล์เป็น `python.py`: อย่าตั้งชื่อชนกับชื่อภาษา ให้ใช้ `hello.py`
